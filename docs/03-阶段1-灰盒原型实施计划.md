# 03 · 阶段 1：灰盒原型实施计划（6/12~13）

> **执行说明（给 AI 编辑器）：** 按任务顺序执行，一次一个任务。技术实现由你决定，但必须遵守文末「命名与架构约定」（后续阶段和文案文档依赖这些名字）。每个任务以"验收"收尾：在 Godot 中运行并核对预期现象，通过后 git commit 再进下一个任务。

**目标：** 用纯色块占位素材（不要任何美术资源），把六大系统和完整流程跑通。本阶段结束时，游戏能从开场字卡一路玩到结局字卡。

**工程位置：** 仓库根目录 `game/` 文件夹，Godot 4.4，渲染器选 Compatibility（为 Web 导出）。

---

## 任务 0：创建工程（人工操作）

在 Godot 4.4 中新建工程到 `game/` 目录，渲染器选 Compatibility。提交一次。

## 任务 1：工程基础配置

- 视口 640×360、窗口 1280×720、canvas_items 拉伸模式、纹理过滤设为 Nearest（像素游戏防糊）
- 输入映射：WASD/方向键移动，E 和空格 = 调查/推进对话（`interact`），Tab = 笔记（`journal`）
- `.gitignore` 忽略 `.godot/`
- **验收：** 工程打开无报错，Input Map 中能看到上述动作

## 任务 2：全局单例（游戏状态 + 场景路由）

- 一个全局游戏状态单例：管理剧情阶段（白天/夜晚/结局）、已收集线索列表、剧情 flag。收集满 5 条线索自动把阶段切到"夜晚"。提供"重置全部状态"的方法（通关重开用）
- 一个场景路由单例：切场景时可指定目标场景中的出生点名字，目标场景据此摆放玩家
- 线索 id 与文本用「约定」一节的表，不得改名
- **验收：** 工程无报错，两个单例已注册

## 任务 3：玩家移动 + 灰盒村庄外景

- 玩家：色块小人，四方向移动，有碰撞，摄像机跟随且不出地图边界
- 村庄外景一张大地图（建议 1280×960），灰盒内容：地面底色、四周边界墙、5 栋房子色块（自己家、陈坚家、张老汉家、义庄、祠堂，各带名字标签）、村子下方留出"棺材地→山路→村口"的纵向入村动线
- 布局意图：棺材地在地图最下方（开场醒来处），祠堂在最上方（终点），玩家被迫纵穿全村
- **验收：** 移动流畅，撞墙撞房被挡，摄像机表现正确

## 任务 4：对话框 + 交互提示 + 线索笔记（全局 UI）

- 对话框：屏幕下方，旁白与对话通用；逐字打字机效果；打字中按 E 立刻出全句，句尾按 E 进下一句，最后一句按 E 关闭；对话期间玩家不能移动，也不能重复触发交互
- 交互提示：玩家靠近可调查物时显示"E 调查"，走开消失
- 线索笔记：Tab 开关，列出已收集线索的文本；没有线索时显示空状态文案（见 07 文档「系统文本」）
- **验收：** 用一段测试对话验证打字机/推进/关闭/锁移动全部正确；Tab 笔记开关正常

## 任务 5：可调查物机制 + 第一条线索

- 做一个可复用的"可调查物"：玩家靠近按 E 弹出若干句文本；可配置"给出某条线索"（按线索 id 登记，重复调查不重复登记）；首次获得线索时追加一句系统提示（文案见 07「系统文本」）
- 在村口放村牌（纯文本调查点，文案见 07「外景调查点」），再放一个临时线索物验证线索登记流程
- **验收：** 提示出现/消失、文本弹出、线索入笔记、重复调查不重复记录，全部正确

## 任务 6：门与场景切换 + 5 个灰盒室内

- 5 个室内场景（自己家、陈坚家、张老汉家、义庄、祠堂）：灰盒房间 + 出口 + 一个线索物（每屋一条，id 见约定表；文案本阶段用占位句即可）
- 村庄外景 5 栋房子各有门，踏入进屋；从屋内出来出现在对应房子门外，**不会立刻再触发进门**（出生点离门留距离）
- **验收：** 5 栋全部进出正常，5 条线索全部可收集且笔记显示正确。收满 5 条后画面变暗属正常（夜晚阶段已触发，演出在任务 8）

## 任务 7：开场字卡

- 黑屏逐张显示旁白字卡（文案：07「开场字卡」，8 张），按 E 推进，淡入中按 E 直接显示全；播完进村，玩家出生在棺材地
- 开场前重置全部游戏状态
- 主场景设为开场字卡
- **验收：** 从 F5 启动到落地棺材地全程正确

## 任务 8：夜幕过场演出（灰盒版）

- 触发条件：已收集 5 条线索且玩家位于村庄外景（在室内收满则出屋时触发），只演一次
- 演出内容：锁玩家操作 → 天色在约 3 秒内变暗 → 弹旁白（07「夜幕过场」4 句）→ 祠堂边出现一个白色人影色块 → 恢复操作
- 之后进出任何场景保持夜晚色调，过场不重播
- **验收：** 按上述时序逐项核对

## 任务 9：结局——祠堂瞎子 + 结束字卡

- 瞎子（色块）只在夜晚出现在祠堂内；白天不可见也不可交互
- 调查瞎子 → 结局对话（07「结局·瞎子」7 句）→ 进入结束字卡（07「结束字卡」3 张）→ 最后一张按 E 回到开场并重置状态
- **验收：** 白天祠堂无瞎子；夜晚流程到重开全部正确，重开后笔记为空

## 任务 10：阶段验收（全流程通关测试）

从启动到通关完整走一遍，逐项核对：

1. 开场 8 张字卡可推进、可跳过淡入
2. 醒来在棺材地，能走到村口调查村牌
3. 5 栋房子进出正常，无"门口循环传送"
4. 5 条线索可收集、笔记正确、不重复记录
5. 第 5 条线索 → 夜幕过场（变暗+旁白+白影）只演一次
6. 夜晚祠堂 → 瞎子对话 → 结束字卡 → 重开后状态清零
7. 全程控制台无红色报错

任一项不符，修复后**重测全流程**。通过后更新 PROJECT_STATUS.md。
