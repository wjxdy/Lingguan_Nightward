# 07 · 剧情文案（游戏内全部文本）

> 本文档是游戏文本的**唯一权威来源**。实施计划里引用的文案如与本文档不一致，以本文档为准。每条数组对应代码里 `lines` 的一个元素（即玩家按一次 E 看到的一句）。
>
> 文风基准：第一人称（名瞳），短句，冷静的恐惧。不用感叹号堆砌恐怖，用"不对劲的日常"。

## 一、开场字卡（opening.gd · CARDS，共 8 张，`\n` 表示卡内换行）

```
1. 一九九五年，六月初六。
2. 我叫名瞳，名花流村人。\n那一天，我跟着师傅的送葬队上山。
3. 师傅死得蹊跷。寿衣的针脚里，缝着我看不懂的符。
4. 我没能走下那座山。\n他们把我钉进了我爹的棺材，埋进了棺材地。
5. 棺材里有一本书。书上的字，是金色的。\n四年，我读完了它。
6. 第四年的雨夜，我引下了那道雷。
7. 轰——（此卡出现时播放雷声，下标 _index == 6）
8. 公元两千年。我回来了。
```

## 二、醒来旁白（村庄首次进入，flag: intro_done）

```
……雨停了。
土腥味。我从土里爬出来，像一根被拔出来的钉子。
四年了。先回村，回家看看。
```

## 三、外景调查点

**破棺（棺材地，玩家身后的土坑）**
```
我爹的棺材。棺盖从里面炸开了，木刺全朝着外面。
四年，我在这里面躺了四年。
里面那本金字的书，已经化成了灰。像是任务完成了，就走了。
```

**村牌（村口）**
```
一块旧村牌。「名花流村」四个字被人用刀划得稀烂。
上面用红漆重新写了三个字——
封门村。
```

**老槐树（村口）**
```
村口的老槐树，打我记事起就在。
树上挂满了红布条。以前求平安才挂，一年也就挂三五条。
现在，挂红的比挂叶的多。
```

**干涸的井（村口内侧）**
```
井绳还在，桶也还在。
我往下看了一眼。井是干的，干得发白。
六月的雨季，井不该是干的。
```

## 四、自己家（home.tscn）

**饭桌**
```
桌上摆着三副碗筷，饭菜原封没动。
我那一副，也摆着。
他们走的那天，在等我吃饭。
```

**灶台**
```
灶膛里的柴烧到一半，自己熄了。
锅里是我娘做的腊肉。
摸上去，还有一点温。……不对。四年了，怎么会是温的。
```

**爹娘的床**
```
被子叠得整整齐齐，这不是我娘的习惯。
我娘的习惯是把被子摊开晒着。
是有人，替他们叠的。
```

**没写完的信【线索 home_letter】**
```
桌角压着一封信，是我爹的字，写给省城的叶叔。
「文强吾兄：村里近来不太平，夜里总有唢呐声，瞳儿坟上的土——」
信到这里断了。墨迹拖出长长的一道，像是笔被人从手里抽走。
```

## 五、师傅家·陈坚家（chen_home.tscn）

**灵堂**
```
师傅的灵堂还没拆，白幡都垂到了地上。
牌位上的字被香火熏黑了，只剩「陈公讳坚」四个字还认得出。
香炉里插着三炷香——是新的，今天才烧过的那种新。
```

**倩倩的房间**
```
倩倩的梳妆台。镜子用红布蒙着。
出殡人家蒙镜子是规矩，可这块红布，钉死在了镜框上。
七颗钉子。钉得很怕，怕里面的东西出来。
```

**药罐**
```
炉上一只药罐，药渣早就干透了。
师傅生前身子骨硬朗，从不喝药。
这药，是熬给谁的？
```

**寿衣【线索 chen_shroud】**
```
里屋的箱子里，叠着师傅下葬那天没穿走的备用寿衣。
我把袖口的针脚拆开了。
里面缝着一条黄符，符上的朱砂已经变黑。
书上说过：符入殓衣，魂不归家。师傅的死，是有人做的局。
```

## 六、张老汉家（zhang_home.tscn）

**屋子**
```
张老汉一个孤老头子，屋里却干净得反常。
地扫过，桌擦过，连蛛网都没有。
全村人都消失了，这屋子却像每天有人打理。
```

**供桌**
```
供桌上没有祖宗牌位，只供着一双鞋。
三寸长，红缎面，绣着并蒂莲。
女人的鞋。死人的尺寸。
```

**床底**
```
床底下塞着一套吹打的家伙——唢呐、铙钹、引魂幡。
张老汉是给我师傅抬棺的人之一。
原来他不光抬棺。他是吹唢呐的那个。
```

**阴婚帖【线索 zhang_wedding】**
```
墙上贴着一张大红帖子，是阴婚的婚帖。
新郎的名字被烟熏得看不清。新娘那栏只画着一只小鞋。
落款的日子我认得——
一九九五年，六月初六。我下葬的那天。
```

## 七、义庄（yizhuang.tscn）

**进门旁白（flag: yizhuang_intro_done）**
```
义庄。村里停尸的地方。
小时候我们打赌，谁敢摸一下义庄的门环。没人敢。
现在，门是开着的。
```

**停尸床**
```
停尸床上的草席留着一个人形的压痕。
压痕是新的。
草席的边角，整整齐齐掖了进去——死人不会自己掖席角。
```

**墙上的符**
```
满墙的镇尸符，一层叠着一层。
最底下的已经发黑脆化，最上面的墨迹还新。
有人一直在补符。补到最近，才停手。
```

**长明灯**
```
义庄的长明灯，按规矩百年不能灭。
灯碗里的油还剩大半。
火，是被人掐灭的。
```

**空棺【线索 yizhuang_coffin】**
```
七口棺材，一字排开。棺盖全都挪开了一道缝。
我一口一口看过去。空的。全是空的。
每口棺材里的镇尸符都过了期，黑得像烧过。
七口棺材的人去了哪？或者说——是「走」了，还是被「领」走了？
```

## 八、祠堂（citang.tscn）

**祖宗牌位**
```
祠堂的牌位从高祖排到我爷爷那辈，密密麻麻几百块。
每一块牌位都被转了个面，字朝里，背朝外。
像是不想让祖宗们，看见村里发生的事。
```

**香炉**
```
祠堂的大香炉里插满了香，全是齐根烧尽的。
炉灰里埋着一样东西。我拨开看了一眼——
是半枚烧焦的红盖头。
```

**全村名册【线索 citang_roster】**
```
供桌上摊着全村的名册，三百一十七口人，一笔一笔记得清楚。
每个名字上都画了一个红圈。圈得很慢，很用力，纸都洇透了。
我翻到最后一页。我爹，我娘。也圈了。
只有一个名字没有圈——
名瞳。我自己。
```

## 九、夜幕过场（village.gd · _night_cutscene）

```
天，毫无征兆地黑了下来。
这不是日落。日落没有这么快，也没有这么静。
远处，祠堂的方向，立着一点白。
——去祠堂。
```

## 十一、结局·瞎子（xiazi.gd · LINES）

```
瞎子：「回来了？」
他坐在名册前，空洞的眼窝正对着我，像是早就等在这里。
瞎子：「四年了。书，读完了吧。」
我有一万句话想问。爹娘在哪，全村人去了哪，谁害的师傅——
瞎子：「都会有答案。但你先得弄明白一件事。」
瞎子：「你从那口棺材里爬出来的时候——」
瞎子：「就已经不算活人了。」
```
