# 04 · 阶段 2：垂直切片实施计划（6/14~15）

> **前置：** 阶段 1 验收通过（灰盒全流程可通关）。本阶段把"开场→棺材地→村口→自己家"这条线做到成品质量，验证素材管线和最终观感；其余地点保持灰盒。开工前按 docs/08 备齐必备素材（字体、tileset、角色行走图、首批音效）。

**目标：** 切片完成后，村口和自己家的截图可以直接用于参赛页面。

## 任务 1：接入中文像素字体

- docs/08 指定的缝合像素字体设为全局默认字体
- **验收：** 字卡、对话框、笔记全部变为像素字体，无中文"豆腐块"缺字

## 任务 2：村庄外景铺图（人工为主）

- 用 TileMap 铺切片区域：棺材地（乱坟、土坑）→ 山路 → 村口（村牌、院墙、老槐树、井）→ 村内小路；装饰层开 Y-Sort，树干坟碑等加碰撞
- 自己家房子换正式外观；其余 4 栋暂保持灰盒
- 沿用灰盒的布局动线，删除被替换的占位色块
- **验收：** 切片沿途地面无破洞、装饰有碰撞、玩家走到物件后方被正确遮挡

## 任务 3：玩家行走动画

- 角色行走图替换色块：四方向行走动画 + 各方向待机帧（左右可镜像）
- **验收：** 四方向走/停的动画与朝向全部正确

## 任务 4：光照氛围（灯笼 + 压暗）

- 夜晚整体压到接近黑，玩家身上挂灯笼光圈（半径约 5 个身位），夜晚自动点亮、白天无光圈；室内外都生效
- 光圈贴图用引擎内置渐变即可生成，不需要外部素材
- **验收：** 夜幕过场后只有灯笼范围可视，远处近黑，恐怖感成立

## 任务 5：音频底床

- 白天村庄：风声循环；夜晚：换低频嗡鸣循环
- 对话每句弹出有极轻的提示音
- 开场字卡"轰——"那张配炸雷声
- **验收：** 上述四处声音按时机出现，音量不刺耳（底床轻、刺音不炸）

## 任务 6：切片区域正式内容

- 村庄首次进入自动播放"醒来旁白"（07「醒来旁白」，含操作提示，只播一次）
- 外景调查点按 07「外景调查点」配齐：破棺、村牌、老槐树、干涸的井
- 自己家填到 4 个可调查物（07「自己家」：饭桌、灶台、爹娘的床、没写完的信【线索】），室内换正式地板家具
- **验收：** 从开场玩到自己家，文案与 07 完全一致，观感达到"可截图"标准

## 任务 7：Web 导出冒烟测试（提前排雷）

- 装导出模板，导出 Web 版，本地起 HTTP 服务在浏览器完整玩一遍切片
- 重点检查：中文字体、音频（浏览器要求首次点击后才出声，属正常）、性能
- **验收：** 浏览器可正常游玩；发现的问题本阶段内解决，不许拖到 6/18

## 阶段验收

- 切片线（开场→棺材地→村口→自己家）观感、音频、文案全部成品级
- 其余区域仍可正常通关（灰盒），全流程无报错
