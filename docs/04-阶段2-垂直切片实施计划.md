## 任务 3：玩家行走动画

**文件：**
- 新增：`game/assets/sprites/player.png`（4 方向行走 spritesheet，来源 docs/08）
- 修改：`game/scenes/player.tscn`、`game/scripts/player.gd`

- [ ] **步骤 1：** `player.tscn` 中删除 `Body (Polygon2D)`，新增 `Anim (AnimatedSprite2D)`：用 spritesheet 建 SpriteFrames，动画命名固定为 `idle_down / idle_up / idle_side / walk_down / walk_up / walk_side`（side 用水平翻转实现左右）
- [ ] **步骤 2：** `player.gd` 在 `_physics_process` 的 `move_and_slide()` 之后追加动画状态机：

```gdscript
	# —— 行走动画 ——
	if velocity.length() > 1.0:
		_facing = velocity
		if absf(velocity.x) > absf(velocity.y):
			anim.play("walk_side")
			anim.flip_h = velocity.x < 0
		elif velocity.y > 0:
			anim.play("walk_down")
		else:
			anim.play("walk_up")
	else:
		if absf(_facing.x) > absf(_facing.y):
			anim.play("idle_side")
			anim.flip_h = _facing.x < 0
		elif _facing.y >= 0:
			anim.play("idle_down")
		else:
			anim.play("idle_up")
```

并在脚本顶部声明：

```gdscript
var _facing := Vector2.DOWN
@onready var anim: AnimatedSprite2D = $Anim
```

- [ ] **验证：** 四个方向走动有行走动画，停下有对应朝向的待机帧，左右移动镜像正确
- [ ] **提交：** `git add game/ && git commit -m "feat: 玩家四方向行走动画"`
