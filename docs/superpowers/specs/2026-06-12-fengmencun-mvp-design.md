# 《灵棺夜行·第一夜》MVP 设计文档

- 日期：2026-06-12
- 目标：2026-06-19 前提交黑客松（官方截止 6/20 24:00，预留 1 天缓冲）
- 引擎：Godot 4.x（GDScript）
- 类型：俯视角 2D 像素 · 中式恐怖 · 剧情探索（"星露谷式"村庄探索的感觉，无种田/战斗/经营系统）

## 一句话概念

主角名瞳被活埋四年后引雷脱困，回村发现全村三百多人一夜消失、村名被改为"封门村"——玩家在死寂的村庄里探索五个地点收集线索，夜幕降临后直面真相的开端。

## 剧情范围（B 方案）

只做小说第一卷的"回村探索"段。送葬遇害、棺中四年等前情用黑屏旁白字卡交代，不做地图。

### 游戏流程（总时长 12~15 分钟）

1. **开场字卡**（约 1 分钟）：黑屏 + 旁白逐行浮现 + 音效，交代前情；炸雷声中画面亮起
2. **醒来·进村**（约 2 分钟）：村外棺材地土坑醒来 → 山路教学（移动、调查键）→ 村口见"名花流村"被划改为"封门村" → 进村
3. **自由探索**（核心段，6~8 分钟）：开放小村庄地图，5 个可进入地点各藏 1 条关键线索，不限顺序；集齐 5 条自动触发夜幕
4. **夜幕降临**（约 3 分钟）：灯笼成为唯一光源，脚本化惊吓演出（窗后人影、白衣身影、唢呐声），引导回祠堂
5. **结局钩子**（约 1 分钟）：祠堂遇瞎子，点破"你已经不算活人了"；黑屏出标题《灵棺夜行·第一夜》+ 制作名单

### 五个探索地点与线索

| 地点 | 线索 | 叙事作用 |
|---|---|---|
| 自己家 | 父母没带走的饭桌、留书 | 情感锚点：人是"一夜间"消失的 |
| 师傅陈坚家 | 倩倩的遗物、被施法的寿衣 | 揭示师傅死因蹊跷 |
| 张老汉家 | 三寸小鞋的踪迹、阴婚帖 | 指向幕后黑手 |
| 义庄 | 空棺材、过期的镇尸符 | 恐怖高潮点 |
| 村祠堂 | 全村名册，三百人名字被红笔圈掉 | 触发夜幕/结局的钥匙 |

## 核心机制决策

- **夜晚无失败机制（A 方案）**：纯氛围恐怖，全部脚本化演出，玩家不会死。不做追逐 AI、不做规则死亡。若 6/17 前进度富余，追逐作为可选加分项再评估
- 六个功能系统，无其他：
  1. 角色移动（四方向，CharacterBody2D）
  2. 调查交互（靠近可交互物出提示，按键触发）
  3. 对话框（旁白/对话，打字机效果；用 Dialogue Manager 插件）
  4. 线索笔记（Tab 打开，列表展示已收集线索）
  5. 剧情 flag（线索计数、阶段推进、触发器）
  6. 昼夜光照切换（CanvasModulate + PointLight2D 灯笼）
