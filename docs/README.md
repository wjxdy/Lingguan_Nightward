## 怎么把计划喂给 AI 编辑器

1. **一次只喂一个任务**。打开当前阶段的实施计划，把"任务 N"整段复制给 AI 编辑器，让它自行决定技术实现
2. **每个任务做完必须验收**。每个任务末尾的"验收"写明预期现象。现象不符就让 AI 修，修不好就回退重做，**不要带病进入下一个任务**
3. **每个任务验收通过后立即 git commit**，这样任何时候搞砸了都能退回上一个能跑的版本
4. 计划只锁两类东西：**行为与验收标准**，以及 03 号文档末尾的「命名与架构约定」（线索 id、场景清单等，剧情文案依赖它们）。其余实现细节 AI 编辑器可自由发挥；但若它要改动约定里的名字，纠正它

## 两条铁律

- **6/13 结束时游戏必须能从头玩到尾**（丑没关系），之后所有工作只是让它变好
- **6/16 之后冻结功能**，只填内容、只修 bug，不加任何新系统
