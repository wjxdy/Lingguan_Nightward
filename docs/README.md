## 怎么把计划喂给 AI 编辑器

1. **一次只喂一个任务**。打开当前阶段的实施计划，把"任务 N"整段（含代码块）复制给 AI 编辑器，让它执行
2. **每个任务做完必须验证**。每个任务末尾都有"验证"步骤，写明操作方法和预期现象。现象不符就让 AI 修，修不好就回退重做，**不要带病进入下一个任务**
3. **每个任务验证通过后立即 git commit**（计划里给了提交信息），这样任何时候搞砸了都能退回上一个能跑的版本
4. 如果 AI 编辑器偏离了计划（自己发明了别的文件名、改了架构），纠正它："按照计划中的文件路径和命名执行"。整套计划的节点名、函数名、文件路径是前后呼应的，擅自改名会导致后面的任务对不上

## 两条铁律

- **6/13 结束时游戏必须能从头玩到尾**（丑没关系），之后所有工作只是让它变好
- **6/16 之后冻结功能**，只填内容、只修 bug，不加任何新系统
