- **验收：** 绕全村一圈无地面破洞、无穿模、无漏碰撞

## 任务 6：夜晚演出加强（脚本化惊吓，仍无失败机制）

在灰盒版"变暗+旁白+白影"之上加 3 个一次性纯演出事件（各占一个 flag，白天不触发，触发后不重复）：

- **窗后人影**：夜晚第一次走近陈坚家窗口——人影闪现半秒即逝 + 短促刺音 + 一句旁白（07「事件 A」）
- **唢呐声**：夜晚走到村中心——远处唢呐渐起渐灭 + 一句旁白（07「事件 B」）
- **白影消失**：靠近祠堂边的白影——白影瞬间消失 + 音效 + 一句旁白（07「事件 C」）

**验收：** 入夜后三个事件各触发一次、不重复；白天踩上去无反应。
