## 任务 6：夜晚演出加强（脚本化惊吓，仍无失败机制）

**文件：** 修改 `game/scripts/village.gd`、`game/scenes/village.tscn`

在灰盒版"变暗+旁白+白影"基础上加 3 个脚本化事件，全部是"一次性、纯演出、不杀玩家"：

- [ ] **事件 A·窗后人影：** 陈坚家窗口位置放 `Sprite2D`（人影剪影，默认隐藏）。夜晚玩家第一次走近（Area2D 触发，flag `night_window_done`）：人影显示 0.5 秒后隐藏 + 一声短促音效 + 一句旁白「窗后面，刚才有张脸。」
- [ ] **事件 B·唢呐声：** 夜晚玩家走到村中心（Area2D，flag `night_suona_done`）：远处唢呐声渐起渐灭（AudioStreamPlayer，3 秒 fade），旁白「谁家在办喜事？……不对。这是送葬的调子。」
- [ ] **事件 C·白影消失：** `NightGhost` 改为挂 Area2D 检测：玩家靠近到 120px 内时白影瞬间消失 + 音效，旁白「走近了，那点白就不见了。好像它只想让我看见，不想让我碰到。」（flag `night_ghost_done`）
- [ ] 三个事件触发器实现模板（挂在 Area2D 上，导出变量配置）：

```gdscript
extends Area2D
## 一次性夜间演出触发器：夜晚阶段玩家进入范围时触发一次。
## 文件：game/scripts/night_trigger.gd

@export var flag_name: String = ""
@export_multiline var narration: PackedStringArray = []
@export var reveal_node: NodePath        ## 可选：触发时短暂显示的节点（事件 A 的人影）
@export var hide_node: NodePath          ## 可选：触发时隐藏的节点（事件 C 的白影）
@export var sound: AudioStream

func _ready() -> void:
	body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node2D) -> void:
	if not body.is_in_group("player"):
		return
	if GameState.phase != GameState.Phase.NIGHT or GameState.has_flag(flag_name):
		return
	GameState.set_flag(flag_name)
	if sound:
		var p := AudioStreamPlayer.new()
		p.stream = sound
		add_child(p)
		p.play()
	if not reveal_node.is_empty():
		var n: CanvasItem = get_node(reveal_node)
		n.show()
		get_tree().create_timer(0.5).timeout.connect(n.hide)
	if not hide_node.is_empty():
		(get_node(hide_node) as CanvasItem).hide()
	Ui.show_dialogue(narration)
```

- [ ] **验证：** 入夜后依次踩到三个触发点，演出各触发一次且不重复；白天踩上去无反应
- [ ] **提交：** `git add game/ && git commit -m "feat: 夜晚三段脚本化惊吓演出"`
