# 08 · 美术与音频资源清单

> 阶段 2 开工前把本清单的「必备」项全部备齐，放入 `game/assets/` 对应目录。**所有素材下载时核对许可证**（CC0 最稳；CC-BY 需在游戏结尾和参赛页面署名——把署名直接加到 ending.gd 的字卡里）。

## 一、字体（必备）

| 项 | 来源 | 说明 |
|---|---|---|
| 缝合像素字体 Fusion Pixel Font | GitHub 搜 `TakWolf/fusion-pixel-font` → Releases | 下 **12px proportional · zh_hans** 的 otf。开源（OFL），中文覆盖全，像素游戏唯一推荐 |

放入 `game/assets/fonts/`。

## 二、地图与角色像素素材（必备）

itch.io 搜索关键词与候选（均为俯视角 16×16，免费版可商用，下载页再次核对许可）：

| 用途 | 候选 | itch.io 搜索词 |
|---|---|---|
| 村庄地表/树木/杂物 | Mystic Woods（free 版）、Kenney Tiny Town | `mystic woods pixel`、`kenney tiny town` |
| 室内地板/家具 | Modern Interiors（LimeZu，free 版）、Pixel Fantasy 系列 | `limezu interiors`、`top down interior 16x16` |
| 墓地/恐怖物件 | 搜墓地主题包 | `graveyard tileset 16x16`、`halloween tileset top down` |
| 主角行走图 | Mystic Woods 自带角色，或单独角色包 | `top down character 16x16 walk` |

**风格统一处理（关键技巧）：** 不同来源的素材色调会打架。全部导入后在 Godot 里给 `Village` 和各室内根节点统一加一层暗冷色 `CanvasModulate`（已在计划中），再把过艳的 tile 用 Aseprite/Photopea（网页版免费）整体降饱和 20~30%、压低明度。脏、旧、灰正是本作要的质感，素材"不够新"反而是优点。

**中式特有物件兜底方案**（素材包里找不到的：棺材、灵幡、纸钱、三寸小鞋、阴婚帖）：
1. 优先：用 AI 绘图生成（见下节）后缩到 16×16/32×32，Photopea 里手动修轮廓
2. 兜底：用近似物改造——西式棺材改色去十字、白旗加竖排黑字当灵幡、黄色小纸片堆当纸钱。距离镜头远、又压了暗色调，糙一点完全看不出来

## 三、AI 绘图生成清单（提升档次用，非必备）

> 用任意 AI 绘图工具（即梦/Midjourney/GPT 等）。生成物是"图片素材"不是"像素图"也没关系：标题画面和立绘不需要像素风格统一，恐怖游戏常用"像素场景 + 高清插画立绘"的混搭。

| 优先级 | 项 | 提示词要点 |
|---|---|---|
| 1 | 标题画面 | 中式恐怖、夜、山村、一口棺材立在村口、灯笼冷光、留出标题文字空间、暗部为主 |
| 2 | 瞎子立绘（结局对话用） | 盲眼老者、灰布衫、坐姿、烛光侧光、半身、黑背景 |
| 3 | 名瞳立绘（可选） | 二十岁青年、土布衣沾泥、苍白、眼神空、半身、黑背景 |
| 4 | 棺材/灵幡/阴婚帖单品图 | 黑背景单物件、俯视角、之后手工缩成小图 |

## 四、音频（必备，全部可在 freesound.org / OpenGameArt 找 CC0）

| 文件名（计划中引用） | 内容 | 搜索关键词 |
|---|---|---|
| `wind_loop.ogg` | 旷野风声循环（白天底床） | `wind ambient loop` |
| `night_drone.ogg` | 低频阴沉嗡鸣循环（夜晚底床） | `dark ambient drone loop` |
| `thunder.ogg` | 炸雷一声（开场） | `thunder crack` |
| `ui_blip.ogg` | 对话提示音（极短、低调） | `ui blip soft` |
| `suona.ogg`（阶段 3） | 唢呐/哀乐片段，找不到就用走调的喇叭声压低音量 | `suona`、`chinese funeral horn`、`detuned horn` |
| `sting_short.ogg`（阶段 3） | 惊吓刺音（窗后人影用） | `horror sting short` |

放入 `game/assets/audio/`。音量基准：底床 -8dB 起调，刺音不超过 0dB，宁轻勿炸耳。
